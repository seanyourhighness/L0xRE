# L0xRE

**[L0xRE-BeeLLama-Low](https://github.com/seanyourhighness/L0xRE-BeeLLama-Low)** is the home of L0xRE-27b-Low, a local coding assistant with DFlash2 speculative decoding and explicit memory profiles.

Start with the **[latest release](https://github.com/seanyourhighness/L0xRE-BeeLLama-Low/releases/latest)** and the [guided installer](https://github.com/seanyourhighness/L0xRE-BeeLLama-Low/blob/main/install/README.md).

The current distribution is **v0.1.2**, a tooling and documentation update that reuses the unchanged **v0.1.1 runtime**. Supported packages target SM86, SM89 and SM120 with explicit 12GB/16GB profiles where available. Windows SM86/SM89 remain build-verified only; GPU capacity alone does not establish hardware qualification. See the [qualification matrix and memory requirements](https://github.com/seanyourhighness/L0xRE-BeeLLama-Low#readme) before installing.
